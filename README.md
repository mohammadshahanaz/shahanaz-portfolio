# Shahanaz Mohammad — Portfolio

A responsive React + Vite portfolio website.

## Run locally

1. Install Node.js (LTS) from https://nodejs.org/.
2. Open this folder in VS Code.
3. Open Terminal in VS Code and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed in the terminal.

## Build check

```bash
npm run build
npm run preview
```

## Deploy to GitHub Pages

1. Push the contents of this folder to the `main` branch of your GitHub repository.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment → Source**, select **GitHub Actions**.
4. Open the **Actions** tab and wait for **Deploy portfolio to GitHub Pages** to finish successfully.

The Vite configuration uses relative asset paths, so it does not depend on the repository name.

## Update resume

Replace `public/resume.pdf` with your latest PDF, keeping the same filename.
