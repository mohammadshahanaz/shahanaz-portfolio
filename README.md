# Shahanaz Mohammad — Professional Portfolio

## Run locally
1. Extract the ZIP.
2. Keep `index.html`, `style.css`, `script.js`, and the `assets` folder together.
3. Open `index.html` in a modern browser, or use VS Code Live Server.

## Included
- Responsive portfolio with a cohesive dark indigo, teal, violet, and coral palette.
- Dedicated experience sections for Infosys Springboard and Cisco.
- Distinct visual treatments for the YOLO diabetic retinopathy and Brazilian e-commerce projects.
- Mehendi and chess hobbies.
- Responsive navigation, theme control, scroll progress, reveal effects, and copy-email interaction.
- Resume PDF included at `assets/Shahanaz_Mohammad_Resume.pdf`, with download links on the page.

## Customize before publishing
Check your contact details and LinkedIn URL. Add GitHub repositories, project demos, and certificate verification links when you have the exact URLs. The site uses Google Fonts online and falls back to system fonts offline.
